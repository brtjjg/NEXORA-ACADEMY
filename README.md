# Nexora Academy 🎓

## Learn. Build. Get Certified. Get Hired.

Nexora Academy is a complete education platform with Pay-As-You-Learn courses, verified certificates, and a student dashboard.

---

## 🚀 Features

### 🔐 Authentication
- Register with email, phone, country
- Login/Logout functionality
- Demo login for quick access
- User data stored in localStorage

### 📚 Courses
- **Computer Packages** - 40+ lessons
- **Web Design** - 35 lessons
- **Python Programming** - 30 lessons
- **Graphic Design** - 28 lessons
- **Digital Marketing** - 32 lessons
- **AI & Machine Learning** - 25 lessons
- **Data Analysis** - 30 lessons
- **Cybersecurity** - 28 lessons
- **Mobile App Development** - 32 lessons

### 💳 Payment System
- Pay-As-You-Learn model
- $2 incremental payments
- Progress-based lesson unlocking
- Payment tracking

### 🏆 Gamification
- 9+ achievement badges
- Progress tracking
- Certificate upon completion

### 🎓 Certificates
- Automatically generated
- Downloadable
- Unique certificate ID
